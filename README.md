# Maze Solver Game

A simple Android maze solver game built with **Kotlin** and **Jetpack Compose**.

## Features

* Generate random mazes
* Choose maze size
* Solve the maze
* Visualize the solution
* Multiple solving algorithms

## Algorithms

* BFS
* DFS
* A*

## Tech

* Kotlin
* Jetpack Compose
* Material 3
* Navigation Compose
* ViewModel

## Screens

* Main Menu
* Maze Screen

## How to Run

1. Clone the repository.
2. Open it in Android Studio.
3. Sync Gradle.
4. Run the app on an emulator or Android device.
